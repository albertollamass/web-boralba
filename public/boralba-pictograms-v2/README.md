# Boralba Technical Badges v2

Sistema visual inspirado en la referencia facilitada: badges compactos 80x80, borde 1.4px, radio 8px, negro #171717 sobre blanco. El dato técnico es protagonista; el dibujo solo ayuda a leerlo.

## Uso
Los SVG incluidos son plantillas visuales. En producción conviene convertirlos en componentes (React/SVG) y sustituir los valores de ejemplo por datos dinámicos del producto. No rasterizar ni rediseñar con librerías de iconos.

## Claves sugeridas
voltage, power, power_per_meter, flux, flux_per_meter, efficacy, frequency, cri, ugr, cct, ip, ik, beam_angle, cut_length, length, dimensions, diameter, cutout, led_width, material_al, diffuser_opal, surface, suspended, recessed, dali, dimming, lifetime, warranty.

## Regla
Mostrar 5–7 badges realmente útiles por producto. Los demás datos permanecen en Datos técnicos.
